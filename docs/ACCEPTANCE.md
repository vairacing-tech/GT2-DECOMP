# Acceptance targets

## Milestone 1: complete Simulation Mode experience

The first major gameplay milestone is reached only when the following flow works end to end:

1. boot from a supported US 1.2 Simulation disc;
2. create or load a save;
3. navigate GT Mode menus;
4. buy a car;
5. enter the garage and manage the car;
6. obtain a license;
7. enter and complete a race;
8. save, restart, reload, and continue progression successfully.

## Regression lenses

- `original` profile: compare against original behavior and visual expectations.
- `enhanced` profile: confirm native feature equivalents remain opt-in by capability and coherent by default.
- `compatible_modified` disc input: confirm patched user discs still ingest and run without being mistaken for unsupported media.
